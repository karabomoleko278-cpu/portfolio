Engineering Decision Records (EDRs)

EDR-001 (Persistence) ACCEPTED

Polymorphic Gig Documents vs. Relational JOINs

System: HustleHub Platform REST Engine

Selected MongoDB dynamic document schemas with embedded sub-documents over normalized PostgreSQL multi-table JOINs to support unpredictable freelance gig service payloads and high-concurrency booking lifecycles.

Write Throughput: +340% Boost
Schema Migration: Zero-Downtime
Trade-off: Required application-level Mongoose schema strictness and transactional sessions for ledger balance invariants.
EDR-002 (Concurrency) ACCEPTED

Lock-Free Circular Ring Buffer vs. Threading Channels

System: Smart-X IoT Mesh Ingestion

Implemented an unmanaged lock-free circular ring buffer (CustomTelemetryRingBuffer<T>) instead of standard System.Threading.Channels for 100k+ pkt/s real-time IoT sensor telemetry streams.

GC Heap Allocations: 0 Bytes (Hot Path)
Enqueue Latency: < 0.42 microseconds
Trade-off: Bounded overwriting semantics accept drop of lowest-priority historical packets when consumer throttles under peak bursts.
EDR-003 (Mobile Sync) ACCEPTED

Room Local SQLite Hash Ledger vs. Optimistic Sync

System: EcoLoop SA Android Municipal Client

Architected a strict offline-first hash-chained Room SQLite transactional store with coroutine dispatchers and Retrofit interceptors rather than optimistic remote-first HTTP sync for rural South African recycling depots.

Data Loss in Blackout: 0.00% Zero-Loss
Reconciliation: SHA-256 Idempotent
Trade-off: Required cryptographic voucher generation on-device with dual-key validation once backend connectivity is restored.
